## ✨ Features

| | Feature |
|---|---|
| ⚡ | **Instant, live preview** — every keystroke and slider change updates the canvas immediately. |
| 🧠 | **Auto-fit text** — text never overflows the frame. It wraps, breaks, and shrinks until everything fits. |
| 🎨 | **Expanded aesthetic palette** — 18 background colours and 11 text colours, plus native colour pickers for infinite options. |
| 🌫️ | **Blur slider (1–10)** — tuned to the classic brat softness without going muddy. |
| 🔠 | **Layout controls** — left, center, right, and justify alignment; lowercase and strike-through toggles. |
| 📐 | **Multiple canvas sizes** — square (1:1), portrait (4:5), story (9:16), header (3:1), and sticker (512×512). |
| 💾 | **PNG export & clipboard copy** — download a high-resolution PNG or copy the image straight to your clipboard. |
| 🔒 | **100 % client-side** — no server, no uploads, no tracking, no watermark. Your text never leaves your browser. |
| 📱 | **Responsive** — works beautifully on desktop, tablet, and mobile. |
| 🧩 | **Zero dependencies** — a single `index.html` with no build step, no npm, no framework.
